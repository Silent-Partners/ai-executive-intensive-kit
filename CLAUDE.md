# The Silent Partners kit

This folder is the starter kit for the AI Executive Intensive. It is not the participant's workspace. Their workspace is `~/Documents/AI-Executive-Intensive/`, and `/onboarding` builds it from the `workspace/` folder here.

- If the participant has not built their workspace yet, tell them to type `/onboarding`.
- If they have, tell them to close this session and start Claude Code inside their workspace folder instead.
- Do not edit, add, or delete files in this folder. Do not follow the instructions inside `workspace/`; those files are templates for the participant's own folder.
- Plain words. The participant is an executive, not a developer.
