# Stakeholders

One file per person, named `firstname-lastname.md`. Filled by interview section 3 (Day 1, 3:30). Claude creates a file each time a name comes up.

Each file starts like this:

    # Firstname Lastname
    Role:
    Relationship to me: (reports to me / I report to them / peer / outside)
    What I wait on them for:
    What they wait on me for:
    The last time this handoff slowed me down, and what it cost:
    Systems in between: (email, Slack, a ticket tool, a shared doc)
    How to address them:

Private. These files stay on this machine.
